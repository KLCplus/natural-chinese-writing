# 自然中文表达

让 AI 把事情说清楚，少一点工作汇报腔。

写实验报告时，你可能见过这样的句子：

> 针对环境兼容性问题开展排查，完成依赖版本适配，实现运行流程闭环。

读完还是不太清楚，程序到底出了什么问题。

这套技能希望把它写成这样：

> 程序启动时提示找不到模块。检查后发现两个依赖的版本不匹配，换成兼容的版本后，程序可以正常运行了。

事情没有变，表达具体了一些。上面是改写示例，实际使用时，原因和结果都要以已有材料为准。

## 为什么做这个

起因是读了几份学长的实验报告。里面会写刚开始哪里没弄懂，尝试过什么办法，后来又发现了什么。也会承认结果不够好，有些地方还没解决。

这种文字读起来比较自然，因为它在讲具体的事。

于是，我们把其中值得保留的表达习惯整理成一个 Skill，方便在写报告、整理说明和日常回答时反复使用。

## 它会怎么写

- 用具体动作讲过程。改了什么、运行后出现什么，尽量直接说。
- 解释概念时，先说它有什么用，再补必要的术语和细节。
- 心得写具体理解，少用“收获颇丰”“奠定坚实基础”这类空泛总结。
- 结果不好就说明哪里不好，不默认给每次实验安排一个圆满结尾。
- 普通说明少用“审计、闭环、赋能”等套话，专业任务需要这些词时照常使用。
- 不为了显得像真人，刻意加错别字、口头禅，或者编造报错和个人经历。

**这里只管语气和措辞。** 标题、字体、章节、表格和篇幅，都按每次任务的要求来，不固定成某份实验报告的排版。

## 再看两个例子

### 写结果

常见的套话：

> 经多维度验证，模型具备良好的泛化性能，达到了预期目标。

如果实际结果是训练表现好、测试表现差，就写：

> 训练集准确率较高，但测试集准确率仍然偏低，模型在新数据上的表现还不够好。

### 交代修改

常见的套话：

> 已完成文档结构优化与内容一致性校验，交付结果具备可用性和可追溯性。

如果实际只是合并了重复段落，就写：

> 改好了。几处重复的内容已经合并，原来的例子也保留了。

这些例子说明的是措辞。不能为了用上某句话，反过来补出没有发生过的事情。

## 安装到 Codex

把这个仓库放到个人技能目录中：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/KLCplus/natural-chinese-writing.git ~/.agents/skills/natural-chinese-writing
```

也可以点击仓库页面的 **Code → Download ZIP**，解压后把文件夹改名为 `natural-chinese-writing`，再放进 `~/.agents/skills/`。

如果只想在一个项目中使用，放到该项目的 `.agents/skills/natural-chinese-writing/` 中即可。关键是保留整个文件夹，让 `SKILL.md` 和它引用的文件放在一起。

目录位置可参考 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。安装后如果技能没有出现，可以重启 Codex 再试。

## 怎么用

在能够识别这套技能的会话中，直接指定名字：

```text
请用 $natural-chinese-writing 改写下面这段实验说明。
保留技术细节，语气自然一些，排版不变。
```

写新内容时也可以这样说：

```text
请用 $natural-chinese-writing，根据我提供的实验记录写一段实验小结。
不要补写没有发生过的操作，格式按老师的要求来。
```

日常回答、课程作业、项目说明也能用。正式材料仍然需要正式，专业概念仍然需要准确，不必把所有内容都写成聊天或实验心得。

如果你用的工具不支持 Skill，也可以把 [SKILL.md](SKILL.md) 中的规则作为写作要求提供给它。具体效果取决于工具和模型。

## 文件说明

```text
natural-chinese-writing/
├── SKILL.md                      # 写作规则
├── agents/openai.yaml             # 技能名称、简介和调用设置
├── references/style-examples.md   # 风格说明与改写例子
└── README.md
```

仓库保留的是整理后的规则和少量说明，不附带原始实验报告、姓名、学号或本地文件路径。

如果你也经常觉得 AI 写的中文太像工作汇报，可以试试这套规则。遇到改完仍然拗口的句子，欢迎在 Issue 里贴一小段不含私人信息的例子，一起把它改得顺一点。
